K9 CREATIVE ACTIVATION - FREE WEBSITE PACKAGE

This package is a ready-to-upload static website for GitHub Pages.
It contains the 31 slides supplied by the client, arranged in exactly the order provided.

HOW TO UPDATE GITHUB PAGES
1. Open your repository: https://github.com/oangkrittaworn-wq/oangkrittaworn-wq.github.io
2. Upload/replace the files and the assets folder from this package.
3. Commit the changes to the main branch.
4. GitHub Pages will publish the update automatically.

IMPORTANT:
- Keep index.html at the repository root.
- Keep the assets folder next to index.html.
- The website URL remains: https://oangkrittaworn-wq.github.io/

The website is static HTML/CSS/JS, so no paid hosting is required for GitHub Pages.
